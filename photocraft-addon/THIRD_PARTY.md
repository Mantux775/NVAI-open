## Binaries bundled inside these packages

- **cffi**: _cffi_backend.cp312-win_amd64.pyd
- **clr_loader**: ClrLoader.dll
- **pillow**: _avif.cp312-win_amd64.pyd, _imaging.cp312-win_amd64.pyd, _imagingcms.cp312-win_amd64.pyd, _imagingft.cp312-win_amd64.pyd, _imagingmath.cp312-win_amd64.pyd, _imagingmorph.cp312-win_amd64.pyd, _imagingtk.cp312-win_amd64.pyd, _webp.cp312-win_amd64.pyd
- **pydantic_core**: _pydantic_core.cp312-win_amd64.pyd
- **pythonnet**: Python.Runtime.dll
- **pywebview**: Microsoft.Web.WebView2.Core.dll, Microsoft.Web.WebView2.WinForms.dll, WebBrowserInterop.x64.dll, WebBrowserInterop.x86.dll, WebView2Loader.dll, pywebview-android.jar

The Microsoft.Web.WebView2.* DLLs and WebView2Loader.dll in pywebview are the Microsoft WebView2 SDK 1.0.3856.49. The wheel contains no license file for them; the SDK license (BSD-3-Clause, "Copyright (C) Microsoft Corporation") is published at https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3856.49/License – its notice has to accompany binary redistributions.

## Other parts

- **Swift (PhotoCraftKit, Mac app):** no third-party Swift packages – only Apple system frameworks.
- **Panel (HTML/CSS/JS):** no third-party libraries, fonts or images; icons are drawn in this repository.
- **Not bundled, required at runtime:** Python 3.12 (installed by the setup via uv), Microsoft Edge
  WebView2 Runtime (Windows, for the panel window), PhotoCraft (installed by the user).
